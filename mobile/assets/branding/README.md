# Copy & Paste logo

Generated with the built-in image generation tool. `app_logo.png` is the master app asset. Platform launcher icons are resized exports of this image; Windows uses a multi-resolution ICO container.

## Generation prompt

Use case: logo-brand. Create the final square launcher icon for Copy & Paste, a minimal Cupertino-style app that securely syncs clipboards between nearby devices. A distinctive simple white geometric symbol of two overlapping rounded clipboard/page outlines, their overlap suggesting a seamless link and transfer between two devices. Bold clean silhouette, balanced optical weight, recognizable at 32 pixels. Solid near-black charcoal background extending to all four square edges. White mark centered within the central 60 percent with generous safe margins. Flat vector-like precision, restrained premium utility-app aesthetic matching a black-and-white iOS interface. No letters, words, watermark, gradients, shadows, 3D effects, external mockup, border, or baked-in rounded outer corners. Produce one finished 1024x1024 opaque square icon.

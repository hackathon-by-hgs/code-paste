# Skill: Agent Handoff

Every meaningful milestone ends with a handoff.

## Required information

```text
What changed
Files changed
Tests run
Architecture decisions
Security considerations
Known limitations
Dependencies
Next steps
```

## Principle

A new agent should be able to continue the work without asking:

> "What did the previous agent do?"

The handoff should answer that immediately.

## Never write

- "Done."
- "Fixed."
- "Everything works."

without evidence.

Instead write exact commands and outcomes.

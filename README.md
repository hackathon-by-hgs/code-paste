# Frontend Web Application

This branch contains the control plane web application for the Clipboard Project.

## Tech Stack
- Next.js (App Router)
- React
- TailwindCSS V4
- TypeScript
- pnpm

## How to run this domain in under 5 minutes

1. Make sure you have `pnpm` installed.
2. Clone this specific branch:
   ```bash
   git clone git@github.com:hackathon-by-hgs/code-paste.git -b frontend --single-branch code-paste-frontend
   cd code-paste-frontend/frontend
   ```
3. Install dependencies:
   ```bash
   pnpm install
   ```
4. Run the development server:
   ```bash
   pnpm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
